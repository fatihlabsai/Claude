# Boğaz Vapuru

İstanbul vapurunu kullanıp Karaköy, Kadıköy, Beşiktaş ve Üsküdar iskeleleri arasında yolcu taşıdığın, tarayıcıda oynanan 2D oyun. Tek bir HTML5 Canvas dosyasıdır; harici dosya, CDN ya da sunucu gerekmez.

**Oyna:** [fatihlabsai.github.io/Claude/bogaz-vapuru](https://fatihlabsai.github.io/Claude/bogaz-vapuru/)

- Tankerlerden, kayıklardan ve akıntıdan kaç; iskelelerden yolcu al, doğru iskelede bırak.
- Martılara simit atarak bonus puan kazan.
- Süreli seferler, giderek artan zorluk, en yüksek skor tarayıcıda (localStorage) saklanır.
- Klavye (ok tuşları) ve mobilde ekrandaki joystick ile "Simit At" düğmesi.

Claude Code ile, Claude Opus 5.5 modeliyle üretildi.
